# Hotspot Mozai Deck

Codex Skill：为“墨仔日记”进行日更图文生产。它会把当日与近 7 天的可核验信号转成以种草、涨粉和自然互动为目标的可选文案，再将选中的主题按文案长度和内容丰富度制作成 4–10 页抖音或小红书图文。

抖音图文与小红书图文的文案生成、平台原生表达、真实性和去 AI 审核，遵循 `master-copywriting` 技能的对应规范；本技能在文案通过该规范后负责墨仔角色、页面拆分与成图。

## 使用方式

- “用墨仔技能出今天 10 条日更文案。”
- “围绕这个已知事件规划 5 页墨仔图文。”
- “只做页面策划和文案，不出图。”
- “文字直接在图上，一次性做好这组墨仔图文。”

日更模式默认提供 10 条有来源的短文案，供挑选后继续制作；只问推荐时提供 3 个精简候选。用户指定事件时直接核验和规划，不强制重新选题。每个选中主题的页数由文案长度、事实和必要信息单元决定，范围为 4–10 页。

## 默认内容目标

墨仔是长期经营的 IP，而不是资讯播报号。除非用户明确要求硬广、卖货或纯资讯，任务默认按 `IP 内容` 或 `IP 种草` 处理：热点负责打开话题，墨仔的观察、判断、情绪陪伴与可带走的实用价值负责建立账号认知和下一次关注的理由。

每篇先选择一个首要互动目标，避免为了“全都要”而牺牲内容自然度：

| 首要目标 | 成品应带来的结果 | 推荐内容抓手 |
|---|---|---|
| 种草 | 读者认可墨仔的内容价值、视角或已证实的解决方案 | 可验证的判断、具体方法、生活场景 |
| 涨粉 | 读者知道为什么还值得继续看墨仔 | 稳定观察角度、判断方法、角色反应、系列化栏目感 |
| 点赞 / 分享 | 读者愿意表达共鸣或转述给他人 | 清晰态度、信息增量、真实共鸣、有记忆点画面 |
| 评论 | 读者有真实的选择或分歧可以回应 | 开放但有边界的问题，不预设立场、不诱导对立 |
| 收藏 | 读者未来需要时愿意回来查看 | 选择依据、步骤、细节、避坑或可复用方法 |

互动必须由正文真实内容自然产生。不得虚构经历、实测、对比或结果，不制造对立、诱导网暴，也不在没有内容理由时硬写“关注、点赞、评论”。

## 平台文案规范

抖音和小红书的文案先遵循已安装的 `master-copywriting` 技能，再进入墨仔页面拆分；该技能负责平台原生、事实边界、身份归属、声明强度、人声处理、审核和 CTA 权限。本技能不复制或覆盖这些规范。

- **抖音图文**：以停留和推进为优先。封面与前页尽快进入动作、场景、问题或信息增量；页面之间持续推进，互动来自正文中的真实选择或分歧。
- **小红书图文**：以搜索和参考价值为优先。标题、关键词与用户问题自然匹配；内容提供真实、具体、可收藏的判断依据，例如适用条件、取舍、细节、对比维度或避坑。
- **默认目的**：未指定商业目的时使用 `IP 内容` 或 `IP 种草`；用户明确要求卖货时，才按对应的商业目的与 CTA 规则执行。

成图前，文案需先完成主文案技能的口语校准、完整审核、去 AI 打散和事实不变量检查。最终冻结逐页文字，避免图内文案和图外文案不一致。

## 日更工作流

1. 搜索当天与近 7 天公开信号，建立事实卡并过滤来源不足的事件；
2. 交付 10 条不同普通人问题的文案候选，每条包含标题、正文、互动主钩子（仅供选题决策，不默认写入文案结尾或图内）、话题与来源口径；
3. 被选中的主题按文案长度与信息量自适应拆成 4–10 页，而不是固定套页数；
4. 依据墨仔人物卡、手账热点视觉和逐页文案生成图文；
5. 默认逐页生成包含全部标题、正文、页码、标签以及（如页面需要）互动句的完整成图，并将最终文件存入当前工作区的主题文件夹。只有用户明确要求留白、纯插画、少字版或后期排字时才切换。

候选阶段还会为每个选题标出一个最适合的互动主钩子：共鸣点赞、可收藏方法、可评论选择、可分享提醒或可持续关注的墨仔观察。它用于帮助选择内容结构，不是强制追加的话术。

## 页数如何自适应

用户指定页数时，按用户要求执行；未指定时，根据文案长度、可证事实数量、背景与解释层次、实用信息密度及独立视觉场景数量确定页数。

- **4–5 页**：单一观点、简短事件说明或轻量情绪表达；
- **6–7 页**：有完整事实链，或需要回答一个关键问题；
- **8–10 页**：背景、变化、影响、方法、对比或多方信息都需要独立讲清。

信息不足时合并页面；单页文字超出可读范围或需要承载两个以上独立信息单元时再增加页面。10 页是上限，不是目标。

## 设计原则

- 事实强度决定标题强度；新闻核心事实必须有可靠来源；
- 页数由文案长度与必要信息单元决定，范围为 4–10 页；
- 墨仔角色保持稳定，动作和持笔道具（笔型按主题自由）服从具体场景；
- 封面定义整套的纸张、墨线、双线边框、角部纹样和点缀色；内页继承这套视觉语言，但不复制封面的角色中心构图。解释、步骤、对比和提醒页优先用信息卡、关键词组或手绘场景承载主视觉，墨仔作为边角陪伴性提示角色；
- 内页装饰以低密度无脸涂鸦、淡网格和局部排线补足纸张质感，不与标题、信息卡或角色争夺注意力；
- 默认完整文字直接上图，并以逐页独立生成和逐字核验为准；少字插画与后期排字仅按用户明确要求启用；
- 默认严格竖版 3:4；逐页读取实际像素验证比例，页码 `01 / N` 至 `N / N` 可放四角、顶部居中或底部居中，但全套须统一位置与字级；
- 采用内缩手绘边框，四侧至少留出 20px 画布外留白；比例、页码或安全区不合格时只重做该页；
- 使用当前环境可用工具，不绑定固定供应商或历史 API 参数；
- 同一页最多两次定向重试，之后改用局部处理或明确说明限制；
- 通过 QA 的全部成图按页面序号保存至当前工作区主题文件夹；运行历史不写入 Skill 本身。
