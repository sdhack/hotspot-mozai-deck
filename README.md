# Hotspot Mozai Deck

Codex Skill：为“墨仔日记”进行日更图文生产。它会把当日与近 7 天的可核验信号转成可选文案，再将选中的主题制作成 4–6 页抖音或小红书图文。

## 使用方式

- “用墨仔技能出今天 10 条日更文案。”
- “围绕这个已知事件规划 5 页墨仔图文。”
- “只做页面策划和文案，不出图。”
- “文字直接在图上，一次性做好这组墨仔图文。”

日更模式默认提供 10 条有来源的短文案，供挑选后继续制作；只问推荐时提供 3 个精简候选。用户指定事件时直接核验和规划，不强制重新选题。每个选中主题的页数由事实和必要信息单元决定，通常为 4–6 页。

## 日更工作流

1. 搜索当天与近 7 天公开信号，建立事实卡并过滤来源不足的事件；
2. 交付 10 条不同普通人问题的文案候选，每条包含标题、正文、互动、话题与来源口径；
3. 被选中的主题按信息量拆成 4–6 页，而不是固定套页数；
4. 依据墨仔人物卡、手账热点视觉和逐页文案生成图文；
5. 默认逐页生成包含全部标题、正文、页码、标签与互动句的完整成图，并将最终文件存入当前工作区的主题文件夹。只有用户明确要求留白、纯插画、少字版或后期排字时才切换。

## 设计原则

- 事实强度决定标题强度；新闻核心事实必须有可靠来源；
- 页数由必要信息单元决定，不固定为 4 页或 5 页；
- 墨仔角色保持稳定，动作和毛笔道具服从具体场景；
- 默认完整文字直接上图，并以逐页独立生成和逐字核验为准；少字插画与后期排字仅按用户明确要求启用；
- 默认严格竖版 3:4；逐页读取实际像素验证比例，并统一底部居中页码 `01 / N` 至 `N / N`；
- 采用内缩手绘边框，四侧至少留出 20px 画布外留白；比例、页码或安全区不合格时只重做该页；
- 使用当前环境可用工具，不绑定固定供应商或历史 API 参数；
- 同一页最多两次定向重试，之后改用局部处理或明确说明限制；
- 通过 QA 的全部成图按页面序号保存至当前工作区主题文件夹；运行历史不写入 Skill 本身。
