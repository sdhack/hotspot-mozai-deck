# v1.9 原始出图基线

适用：默认墨仔热点图文，或用户要求“按 1.9”“原始画风”“手账热点卡片”“画面更有涂鸦感”时。它是当前技能的视觉基线，不取代用户明确指定的极简、留白、纯插画或品牌视觉体系。

## 固定视觉语言

- 暖白、略带纤维感的纸张；全页极淡铅笔网格。
- 黑色手绘墨线，有自然粗细、稀疏交叉排线、点描和轻微晕染；避免光滑矢量、3D 塑料感和重阴影。
- 使用淡蓝、淡桃、浅鼠尾草绿、淡薰衣草的低饱和水彩/蜡笔色块；它们承托信息，不抢文字。
- 内缩细双线边框；四角使用相互呼应、低密度的卷草、叶片、蝴蝶结或星点纹样。边框外保留连续暖白外留白，边框不贴边。
- 背景涂鸦仅允许无生命图形：星星、叶子、铅笔、箭头、圆点、闪光、音符。它们低对比、分散、服务阅读，不能挤占文字和主场景。

## 信息与场景

- 封面使用：2 枚顶部 pastel 标签、最多两行钩子标题、第二行波浪下划线、极短副标题、主题相关中层背景、中心主情境、3–4 枚底部关键词标签。封面默认不放页码。
- 封面中层背景：在标题留白区与墨仔之间增加一层与主题直接相关的手绘水彩小景（如场景道具、地点物件），低对比、约四成线强、明确淡于前景，形成景深；场景内禁止任何人物与人脸五官；不得压住标题、副标题或胶囊，墨仔轮廓须在浅色背景前保持清晰。没有稳定主题场景时才退回纯留白。
- 内页使用：左上唯一小圆圈页码、居中标题及波浪下划线、一个信息主场景或清晰内容块。
- 封面是整套视觉母版；内页继承暖白纸、墨线、双线边框、角部纹样与色板，但解释、步骤、对比和提醒页必须让信息卡、关键词组或手绘场景成为主视觉。墨仔保持为可辨认的边角辅助角色，不得无内容理由占据内页中心或压缩正文阅读区。
- 默认完整文字成图仍有效；当用户明确要求多画面或少文字时改用场景叙事：每页一个主动作、一条因果路径，文字仅保留标题、短标签或一句金句。不要将手机、道具、盾牌和箭头摆成没有因果关系的图标拼贴。
- 留白指文字、人物与主场景之间的低噪声阅读安全区，不是让画布边缘大片无内容。纸纹、网格和低密度涂鸦可连续存在。

## 墨仔锚点

- 每页恰好一个墨仔、两条手臂、两条腿、两片叶子；大眼、克制小黑嘴、无腮红。
- 默认右手清楚拿小毛笔/墨滴小画笔。若双手必须完成主题动作，毛笔需放在紧邻场景内可见，不能为此增加手臂。
- 表情和动作必须对应页面内容，并在系列中至少通过眼神、嘴型、姿态、视线或位置改变一项。不能为了“变化”选择与信息冲突的表情。

## 五卡一致性模式

默认五卡一致性：`mozai-ip-sheet-4k.png`、`mozai-ip-sheet.png`、`mozai-three-view.png`、`mozai-expressions.png` 与 `mozai-core-settings.png` 全部作为当前图像工具的参考输入，以保证墨仔跨页一致。工具限制时按主卡 → 标准卡 → 三视图 → 表情卡 → 核心设定卡顺序降级，不得低于三张；用户明确要求复用 v1.9.0 四卡规则或最少参考图时按用户要求执行。即便使用全部人物卡，Prompt 也必须锁定：每页只有一个墨仔、恰好两条手臂和两条腿、恰好两片叶子、右手清楚持毛笔，并声明参考图仅作外观真值。成图后检查人物卡内的文字、示意角色与表情库没有误带入画面。

## 交付验收

1. 成图实际比例严格为 3:4；只看预览不算验收。
2. 内框、文字、角色与角花均不侵占 20px 外留白；整套纸张、边框家族、色板和页码位置统一。
3. 内页页码连续、位置一致、仅出现一次；封面除非用户要求不放页码。
4. 核对文字、人物数量、四肢、叶子、右手毛笔与无脸背景涂鸦。比例、页码、外留白、重复角色属于阻断项；同页最多两次定向重试。

## Prompt 必填提示

在 `STYLE` 中明确纸张、网格、双线边框、四角纹样、涂鸦和手绘材质；在 `CHARACTER` 中写明右手毛笔与当前表情动作；在 `LAYOUT` 中写明封面/内页层级、固定页码位置、阅读安全区与事件路径。不要在 Prompt 中写十六进制颜色代码。
