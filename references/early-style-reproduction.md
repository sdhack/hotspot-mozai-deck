# 早期作品复刻模式（GPT Image 2）

仅当用户明确要求复刻账号早期作品、手账热点卡片，或提供相同视觉参考时阅读本文件。它基于已下载的早期墨仔图文样本：暖白纸张、粗糙黑色铅笔/蜡笔线稿、单角色、强标题层级和三枚关键词胶囊。

## 视觉锁

- 竖版 `3:4`；四周保留约 3% 留白，使用细黑线手绘边框，角部可有低密度卷草、叶片或蝴蝶结。
- 背景是暖白至浅米黄、有纤维颗粒的纸张；可在局部加入极淡方格纸纹理。
- 画面以黑色铅笔、蜡笔涂黑和细排线为主，允许自然线宽变化和轻微不规则；拒绝摄影、塑料 3D、光滑商业矢量和霓虹渐变。
- 点缀色仅用雾蓝、蜜桃粉、浅橄榄绿、淡奶黄；红色只用于必要的警示符号。不要把整页涂成大色块。
- 封面默认采用：两枚顶部标签 → 两行大号手写标题 → 波浪下划线 → 一行事件副标题 → 中部单一情境 → 下方墨仔 → 三枚底部关键词胶囊。
- 内容页优先在“三张叠卡、四宫格、左右对比、单一流程图”之间选择；每页只解释一个结论。
- 墨仔通常在下方三分之一或侧下方；内容页可为次要主体，但必须可辨认。参考图可用时，仍以 `character-lock.md` 的身份锚点为准。

## 文字与生产策略

中文标题、日期、数字和标签必须逐字核对。即使模型支持中文，也优先生成插画、标题留白区、标签底板和信息卡；将长正文、来源和复杂清单放到可控后期排版。端到端生成时，限制为两行短标题、两枚顶部标签和三枚底部关键词。文字错误经过两次定向重试仍存在时，改为后期叠字，不能以模糊文字交付。

## 四页基础模板

### 1. 封面：热点冲突

用上述骨架的封面布局。标题用“事实 + 反差 / 问题 / 明确利益点”，不夸大。中部只画一个能代表事件的情境；墨仔表现为观察、警觉或提问。底部三枚胶囊对应议题的三个可核验关键词。

### 2. 解释页：三张信息卡

顶部显示 `02/04` 和不超过 12 字的结论标题。画三张上下错落的浅色手账信息卡，每张只有一个图标和一个可后期排版的短要点区域。墨仔在右下角持清单或放大镜。不要把长段正文塞进卡片。

### 3. 行动页：四格清单

顶部显示 `03/04` 和一个行动导向标题。中部采用清楚的 2×2 网格或中心辐射图，四个物件 / 小场景分别表达四项行动；卡片标题预留短文本区域。墨仔位于下方角落，做搬运、勾选、指向或扶盾牌动作。

### 4. 收束页：一句提醒 + 互动

顶部显示 `04/04`，一行安抚但不轻率的结论标题。保留大面积空白，将一条经核验的安全提醒或互动问题放在可后期排版的对话框中。墨仔居中或下方举牌 / 挥手；背景使用与主题相关的简洁象征物，避免新增事实。

## QA 补充

在常规 QA 外，复刻模式还必须检查：纸张不是纯白平面；线稿带有真实手绘排线；点缀色不过量；封面标题层级清楚；三枚底部胶囊间距均匀；一页只承载一个结论；图片内所有短中文、数字、日期均已逐字复核。
