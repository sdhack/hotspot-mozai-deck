# Hotspot Template · 热点搜索与候选选题模板

---

## Step 1：搜索策略

用 `general_search` 工具，至少 2 个 query 并行搜索：

**Query 1（社会热点）**：
```
{{年份}}年{{月}}月{{日}}日 最新热点 社会新闻 热搜 争议 突发
```

**Query 2（民生热点）**：
```
今日民生热点 职场 消费 教育 食品安全 {{年份}}.{{月}}.{{日}}
```

**Query 3（实用话题，v1.2.0 新增，高收藏高转发）**：
```
{{当前时间节点}} 实用指南 避坑 清单 攻略 收藏 {{年份}}.{{月}}
```
示例（开学季）：`开学季 新生指南 避坑 清单 攻略 2026.08`
示例（节假日）：`国庆假期 出行攻略 避坑 清单 2026.09`

**搜索要求**：
- 收集至少 10 条候选信号
- 优先官方、主流媒体、平台热榜、原始发布者
- 对新闻、政策、人物、社会事件做交叉核验
- 无法核实的信号标注"网上正在讨论"或放弃
- **优先收集有实用价值的话题**（v1.2.0 新增：基于实战数据，实用科普/防骗/清单类收藏率转发率最高）

---

## Step 2：选题筛选标准

从 10+ 候选中选 5 个，按以下标准打分：

| 维度 | 权重 | 说明 |
|---|---|---|
| 人群相关度 | ★★★ | 目标受众（抖音年轻用户）是否关心 |
| 情绪强度 | ★★★ | 是否有冲突、反差、愤怒、共鸣 |
| 评论潜力 | ★★★ | 是否容易引发讨论、站队、分享经历 |
| 收藏价值 | ★★★（v1.2.0 提升权重） | 是否有实用信息、避坑指南、知识增量，可收藏备用 |
| 转发价值 | ★★★（v1.2.0 新增） | 是否有"可转发给亲友"的理由，如防骗提醒、实用清单 |
| 时效性 | ★★ | 是否是当天或近2天的热点 |
| 差异化 | ★★ | 是否避开已做过的选题和同质化内容 |
| 墨仔适配度 | ★★ | 是否适合墨仔做"操作员/观察员"隐喻 |

**排除规则**：
- 已做过的选题（见 SKILL.md "已做选题记忆"）
- 纯娱乐八卦（无社会讨论价值）
- 过于敏感的政治话题
- 无法核实事实的谣言
- 纯广告/推广内容

## Step 3：页数决定逻辑（v1.5.1 新增，必须先决定页数再出结构）

**核心原则**：根据选题的内容长度和信息量决定页数，禁止默认全部5页。

| 页数 | 适用场景 | 内容特征 | 结构 |
|---|---|---|---|
| **4页** | 单一事件、观点集中、情感驱动型 | 核心冲突单一，分析3点+方案3点即可说清 | 封面 + 分析 + 方案 + 金句/互动（合并） |
| **5页** | 双事件驱动、争议性强、多维度展开 | 两个以上事件交织，或争议性强需呈现多方声音，或信息量较大需独立金句页 | 封面 + 分析 + 方案 + 金句 + 互动（独立） |
| **6页** | 内容特别丰富、多案例/数据支撑 | 多个独立案例/数据/场景需分别呈现，或需深度拆解+背景+案例+方案+金句+互动 | 封面 + 背景/分析1 + 分析2/案例 + 方案 + 金句 + 互动 |

**页数决定检查清单**：
- [ ] 这个选题是单一事件还是多事件交织？
- [ ] 核心观点是否3点以内就能说清？
- [ ] 是否有强争议性需要呈现多方声音？
- [ ] 金句和互动是否需要分开独立成页？
- [ ] 是否有多个案例/数据需要分别呈现？

> ⚠️ **禁止**：不做页数评估直接默认5页；所有候选选题统一用相同页数；内容很少的选题硬凑5页导致每页空洞。

## Step 4：5 个候选选题呈现模板

每个选题按以下格式呈现：

```
## 候选选题 {{编号}}：{{选题标题}}

**热点概述**：{{2-3句话说清事件、时间、地点、核心冲突}}

**为什么适合**：{{1-2句话说明情绪点、共鸣点、讨论空间}}

**收藏/转发价值**：{{1句话说明为什么用户会收藏或转发}}（v1.2.0 新增）

**墨仔角色**：{{墨仔在这个选题中扮演什么角色，做什么动作}}

**建议页数**：{{4页/5页/6页}}——{{1句话说明页数理由，引用Step 3页数决定逻辑}}

**墨仔角色**：{{墨仔在这个选题中扮演什么角色，做什么动作}}

**{{N}}页结构**：
1. 封面：{{封面标题钩子}}（明确数字：N件事/N个坑/N招）
2. P2：{{问题/分析页标题}}（{{N个要点，与封面数字一致}}）
3. P3：{{解决方案/深度页标题}}（{{N个要点，与封面数字一致}}）
4. P4：{{落点页标题}} + 互动（{{互动问题}}）
```

> ⚠️ **数字一致性检查（v1.2.0 新增）**：呈现选题时，封面的数字（N件事/N个坑）必须与 P2/P3 的要点数量一致。不一致时先调整再呈现。
>
> ⚠️ **页数与内容匹配检查（v1.5.1 新增）**：建议页数必须与选题的内容长度和信息量匹配，禁止内容很少的选题建议5页，也禁止内容丰富的选题压缩到4页导致信息过载。

## Step 6：等用户选择

呈现完后，等用户回复：

## 高收藏高转发话题类型（v1.2.0 新增，基于实战数据）

基于实战数据（校园贷防骗爆款：2.3万播放、247分享、205收藏、+8粉丝），以下类型的话题收藏率和转发率最高：

| 类型 | 说明 | 示例 | 墨仔角色 |
|---|---|---|---|
| 防骗/避坑指南 | 可转发给亲友提醒 | "校园贷防骗""兼职骗局""租房陷阱" | 防坑检测员 |
| 实用清单/攻略 | 可收藏备用 | "开学必备清单""报到流程""简历模板" | 避坑辅导员 |
| 时间节点攻略 | 结合当前时间节点 | "开学季""毕业季""节假日出行" | 时间节点向导 |
| 权益保护 | 与年轻人切身利益相关 | "试用期权益""租房合同""劳动仲裁" | 合同操作员 |
| 消费避坑 | 年轻人高频消费场景 | "二手平台骗局""医美陷阱""健身房跑路" | 消费检测员 |

### 低收藏低转发话题类型（谨慎选择）

| 类型 | 说明 | 改进方向 |
|---|---|---|
| 纯社会评论 | 只有观点没有实用信息 | 增加"怎么办"的解决方案 |
| 纯情绪宣泄 | 只有愤怒没有行动指引 | 增加可操作的建议 |
| 过于专业的知识 | 受众面窄 | 用通俗语言+实用场景 |

### 选题策略建议

1. **优先选择实用类**：5个候选选题中，至少2-3个应该是高收藏高转发的实用类话题
2. **结合时间节点**：开学季、毕业季、节假日等时间节点的实用话题天然有流量
3. **明确转发理由**：选题描述中要明确"用户为什么会转发给亲友"
4. **差异化**：避免与已做过的选题同质化，即使是同类话题也要换角度
