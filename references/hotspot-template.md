# Hotspot Template · 热点搜索与候选选题模板

---

## Step 1：搜索策略

用 `general_search` 工具，至少 2 个 query 并行搜索：

**Query 1（社会热点）**：
```
{{年份}}年{{月}}月{{日}}日 最新热点 社会新闻 热搜 争议 突发
```

**Query 2（民生热点）**：
```
今日民生热点 职场 消费 教育 食品安全 {{年份}}.{{月}}.{{日}}
```

**搜索要求**：
- 收集至少 10 条候选信号
- 优先官方、主流媒体、平台热榜、原始发布者
- 对新闻、政策、人物、社会事件做交叉核验
- 无法核实的信号标注"网上正在讨论"或放弃

---

## Step 2：选题筛选标准

从 10+ 候选中选 5 个，按以下标准打分：

| 维度 | 权重 | 说明 |
|---|---|---|
| 人群相关度 | ★★★ | 目标受众（抖音年轻用户）是否关心 |
| 情绪强度 | ★★★ | 是否有冲突、反差、愤怒、共鸣 |
| 评论潜力 | ★★★ | 是否容易引发讨论、站队、分享经历 |
| 收藏价值 | ★★ | 是否有实用信息、避坑指南、知识增量 |
| 时效性 | ★★ | 是否是当天或近2天的热点 |
| 差异化 | ★★ | 是否避开已做过的选题和同质化内容 |
| 墨仔适配度 | ★★ | 是否适合墨仔做"操作员/观察员"隐喻 |

**排除规则**：
- 已做过的选题（见 SKILL.md "已做选题记忆"）
- 纯娱乐八卦（无社会讨论价值）
- 过于敏感的政治话题
- 无法核实事实的谣言
- 纯广告/推广内容

---

## Step 3：5 个候选选题呈现模板

每个选题按以下格式呈现：

```
## 候选选题 {{编号}}：{{选题标题}}

**热点概述**：{{2-3句话说清事件、时间、地点、核心冲突}}

**为什么适合**：{{1-2句话说明情绪点、共鸣点、讨论空间}}

**墨仔角色**：{{墨仔在这个选题中扮演什么角色，做什么动作}}

**4页结构**：
1. 封面：{{封面标题钩子}}
2. P2：{{问题/分析页标题}}（{{3个要点}}）
3. P3：{{解决方案/深度页标题}}（{{3个要点}}）
4. P4：{{落点页标题}} + 互动（{{互动问题}}）
```

| 1 | {{选题1}} | {{类型}} | ★★★★★ | ★★★★★ | ★★★★ | 今天刚热搜 |
| ... | ... | ... | ... | ... | ... | ... |

**我的推荐**：选题 {{编号}}（{{选题标题}}）—— {{1-2句话说明推荐理由}}

---

## Step 5：等用户选择

呈现完后，等用户回复：
- 编号（1-5）→ 进入出图阶段
- "其他"或指定热点 → 重新搜索或直接用用户指定的热点
- 修改建议 → 调整后重新呈现

## 常见选题类型与墨仔角色映射

| 选题类型 | 墨仔角色 | 典型动作 |
|---|---|---|
| 职场/权益 | 合同操作员 | 拿劳动合同、offer、补偿清单 |
| 消费/陷阱 | 防坑检测员 | 拿放大镜、检测笔、电子秤 |
| 教育/争议 | 教育观察员 | 拿成绩单、教案、"耻辱"牌子 |
| 食品安全 | 食品安全检测员 | 拿甲醛检测笔、白菜、显微镜 |
| 安全/事故 | 安全检查员 | 拿安全帽、爆炸示意图、房屋裂缝照片 |
| 科技/AI | 技术接线员 | 在AI和人工之间拉线、拿耳机 |
| 社会/荒诞 | 现场调查员 | 拿放大镜、手铐、账单 |
| 开学/科普 | 避坑辅导员 | 拿防骗手册、清单、盾牌 |
