# QA Checklist · 交付前检查清单

生成 4 张图后、交付前，逐项检查。发现问题立即修正或重生成。

> v1.7.0 新增：J11-J15 检查项——去说教原则（文案+配图）、涂鸦天性（背景无大面积纯白空白）、image_edit request_list 格式。

---

## A. Seedling 角色一致性（每页必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| A1 | 角色数量 | 每页恰好 1 个 Seedling，无第二个角色 | 重生成，prompt 强调 EXACTLY ONE + 角色 ONLY 在指定位置 |
| A2 | 卡片/图标无角色 | 卡片里的图标是无生命物体，无小墨仔/无脸/无泪滴形 | 重生成，每个图标标注 "inanimate icon, NO face, NO character" |
| A3 | 身体形状 | 圆胖黑泪滴，非修长/球形/尖顶 | 重生成，prompt 强调 round plump teardrop |
| A4 | 身体质感 | 哑光墨黑+铅笔/蜡笔涂鸦纹理，非纯平黑/发光 | 重生成，prompt 强调 scribble texture |
| A5 | 卷须 | 细卷发须+螺旋形线圈，非简单圆圈/直茎 | 重生成，prompt 强调 spiral-shaped coil loop |
| A6 | 叶子 | 恰好两片浅鼠尾草绿叶，非一片/三片/无叶 | 重生成，prompt 强调 exactly TWO leaves |
| A7 | 眼睛 | 大圆眼+大白眼白+黑瞳孔，常不对称；非小白点眼/瞳孔居中 | 重生成，prompt 强调 large eyes asymmetrical |
| A8 | 嘴巴 | 深红/暗红，每页表情不同；非黑嘴/无嘴/每页同形状 | 重生成，prompt 指定不同 mouth expression |
| A9 | 手臂 | 恰好两条细黑手臂，非多余/缺失 | 重生成，prompt 强调 exactly TWO arms |
| A10 | 腿 | 恰好两条短粗腿，非多余/缺失 | 重生成，prompt 强调 exactly TWO legs |
| A11 | 阴影 | 脚下有小阴影 | 可接受，不强制 |
| A12 | 角色尺寸 | 活跃时占页面高度 12-22%，非填满页面 | 可接受，不强制 |
| A13 | 角色是动作主体 | 在做与页面主题相关的动作，非角落装饰 | 重生成，prompt 强调 actor role |

## C. 文字准确性（每页必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| C1 | 字体风格 | 全部中文手写风格，标题粗毛笔/马克笔，正文随意铅笔 | 重生成 |
| C2 | 无英文 | 无任何英文文字（包括 MOZAI、SEEDLING、STOP 等） | 重生成或后期裁剪 |
| C3 | 无角色名 | 无"墨仔""MOZAI""SEEDLING"等角色名文字 | 重生成或后期裁剪 |
| C4 | 无版本标签 | 无"v2.0""v1.0"等版本标签 | 重生成或后期裁剪 |
| C5 | 标题准确 | 封面/每页标题文字与 prompt 一致，无错字漏字 | 可接受小瑕疵，严重则重生成 |
| C6 | 页码位置 | 正文页页码仅左上角，无右上角重复页码 | 重生成或后期裁剪 |
| C7 | 无乱码 | 无 gibberish、无意义符号、乱码文字 | 重生成 |
| C8 | 文字不溢出 | 文字在边框内，不被裁剪 | 可接受小瑕疵 |

## D. 数字一致性（跨页必查，v1.2.0 新增）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| D1 | 封面与正文数字一致 | 封面说"N件事/N个坑"，P2/P3 的卡片/步骤数量必须等于 N | 增加卡片/步骤，或改封面标题 |
| D2 | 正文编号连续 | 文案正文的编号（第一/第二/...）连续到 N，无跳号 | 修正文案 |
| D3 | P2 与 P3 数量对应 | P2 的问题数量 = P3 的解决方案数量（或明确说明覆盖关系） | 调整卡片/步骤数量 |
| D4 | 标签数量一致 | 封面底部标签数量 = P4 顶部标签数量（或有明确理由） | 调整标签 |

## G. 内容与构图（每页必查）

| # | 检查项 | 标准 |
|---|---|---|
| G1 | 封面有钩子 | 封面标题有冲突/反常识/情绪钩子，紧贴热点 |
| G2 | P2 是问题/分析 | 3-4 个卡片/要点，逻辑清晰 |
| G3 | P3 是方案/深度 | 3-4 个步骤/做法 + 金句框 |
| G4 | P4 是落点+互动 | 温暖场景 + 墨仔举牌 + 对话气泡互动 |
| G5 | 构图不拥挤 | 有足够留白，元素不堆叠 |
| G6 | 排版优化（v1.2.0） | 卡片有折叠角/双线边框/大圆圈编号；标题有小图标；页码有圆圈 |
| **G7（v1.7.0新增）** | **去说教标题/卡片** | **标题和卡片措辞是分享式（"我自己的3个小习惯"），非命令式（"3个防坑做法，新生必看"）** |

## H. 文案检查（交付前必查）

| # | 检查项 | 标准 |
|---|---|---|
| H1 | 第一人称 | 墨仔第一人称"我" |
| H2 | 口语化 | 像跟朋友说话，无书面语/官话 |
| H3 | 事实可核查 | 热点事实准确，无编造数字/来源 |
| H4 | 结构完整 | 钩子→事实→3-4要点→方案→金句→互动 |
| H5 | 无 AI 味 | 无"首先其次最后""综上所述""让我们一起"等套话 |
| H6 | 互动具体 | 互动问题具体可回答，非"你怎么看" |
| H7 | 字数 | 200-300字 |
| H8 | 话题标签 | 2-4个相关标签 |
| H9 | 与往期爆款不重复（v1.2.0） | 开头、结构、金句、互动问题都与已发布内容不同 |
| H10 | 数字与配图一致 | 文案中的"N件事/N个坑"与配图封面、卡片数量一致 |
| **H11（v1.7.0新增）** | **去说教口吻** | **文案是分享者（"我自己的办法是""我踩过的"），非教导者（"你必须""你应该""你千万不要"）** |
| **H12（v1.7.0新增）** | **去说教标题/提问** | **标题非"新生必看"，互动提问非"你学会了吗"，改用分享式** |

## I. 交付格式

- [ ] 4 张图用 `present_files` 逐张交付（每张配简短介绍）
- [ ] 最后附总结表（4页标题、墨仔动作、状态）
- [ ] 附配套文案（标题+正文+话题标签）
- [ ] 说明小瑕疵（如有）和修正选项
- [ ] 把选题名称追加到 SKILL.md "已做选题记忆"

## 常见问题快速修复

| 问题 | 原因 | 修复方法 |
|---|---|---|
| 出现第二个角色 | prompt 不够强 | 重生成，强调 EXACTLY ONE + 角色 ONLY 在指定位置 + NO character in cards |
| 卡片/图标里出现小墨仔 | 图标被渲染成角色 | 重生成，每个图标标注 "inanimate icon, NO face, NO character" |
| 出现英文 MOZAI/SEEDLING | 模型误渲染 prompt 中的词 | 重生成，在 Avoid 列表明确列出，或后期裁剪 |
| 页码右上角重复 | prompt 不够强 | 重生成，强调 upper-left ONLY, no duplicate on right |
| 嘴巴每页都一样 | 未指定每页不同嘴型 | 重生成，每页 prompt 指定不同 mouth expression |
| 多余数字标注（50%、10%、32s、28%） | 模型误渲染 | 重生成，Avoid 列表加 random numbers, percentages, time labels + 具体例子 |
| P4 出现两个对话气泡 | prompt 不够强 | 重生成，强调 EXACTLY ONE speech bubble, NO second/duplicate |
| 封面数字与正文不一致 | 设计时未核对 | 生成前核对：封面N件=正文N件；不一致则增加卡片或改封面 |
| 文案与往期爆款重复 | 开头/结构/金句雷同 | 换开头（场景化切入）、换结构、换金句、换互动问题 |
| 角色太胖/太瘦 | 身体形状描述不够 | 重生成，强调 round plump teardrop (not slim, not spherical) |
| 文字错字/漏字 | 模型渲染不准 | 可接受小瑕疵，严重则重生成，减少文字量 |
| **背景大面积纯白空白（v1.7.0新增）** | **未强调涂鸦背景** | **重生成，强调 FAINT PENCIL GRID + SCATTERED TINY DOODLE ICONS + cross-hatching patches + ink dots, NO large empty white spaces** |
| **标题/卡片说教式（v1.7.0新增）** | **措辞用了命令式** | **改标题/卡片为分享式（"我自己的3个小习惯"而非"3个防坑做法，新生必看"）** |
| **文案教导式（v1.7.0新增）** | **用了"你必须""你应该"** | **改文案为第一人称分享（"我自己的办法是""我踩过的"）** |
| **image_edit报错（v1.7.0新增）** | **用了扁平参数** | **改用request_list数组格式调用** |
