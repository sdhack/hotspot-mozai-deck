# QA Checklist · 交付前检查清单

生成 4 张图后、交付前，逐项检查。发现问题立即修正或重生成。

---

## A. Seedling 角色一致性（每页必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| A1 | 角色数量 | 每页恰好 1 个 Seedling，无第二个角色 | 重生成，prompt 强调 EXACTLY ONE + 角色 ONLY 在指定位置 |
| A2 | 卡片/图标无角色 | 卡片里的图标是无生命物体，无小墨仔/无脸/无泪滴形 | 重生成，每个图标标注 "inanimate icon, NO face, NO character" |
| A3 | 身体形状 | 圆胖黑泪滴，非修长/球形/尖顶 | 重生成，prompt 强调 round plump teardrop |
| A4 | 身体质感 | 哑光墨黑+铅笔/蜡笔涂鸦纹理，非纯平黑/发光 | 重生成，prompt 强调 scribble texture |
| A5 | 卷须 | 细卷发须+螺旋形线圈，非简单圆圈/直茎 | 重生成，prompt 强调 spiral-shaped coil loop |
| A6 | 叶子 | 恰好两片浅鼠尾草绿叶，非一片/三片/无叶 | 重生成，prompt 强调 exactly TWO leaves |
| A7 | 眼睛 | 大圆眼+大白眼白+黑瞳孔，常不对称；非小白点眼/瞳孔居中 | 重生成，prompt 强调 large eyes asymmetrical |
| A8 | 嘴巴（v1.5.0 更新） | 小黑色/深色嘴，每页表情不同；张嘴时必须含粉舌拟人化（非全黑洞）；嘴不能太大；非深红/无嘴/每页同形状/大嘴/全黑洞 | 重生成，prompt 指定不同 mouth expression；张嘴强调 SMALL open oval + visible PINK/RED TONGUE + NOT all-black |
| A9 | 手臂（v1.5.0 强化） | 恰好两条细黑手臂，非多余/缺失/三臂 | 重生成，prompt 强调 EXACTLY TWO arms + NO extra limbs + NO third arm |
| A10 | 腿（v1.5.0 强化） | 恰好两条短黑腿，非多余/缺失/三腿 | 重生成，prompt 强调 EXACTLY TWO legs + NO extra limbs + NO third leg |
| A11 | 阴影 | 脚下有小阴影 | 可接受，不强制 |
| A12 | 角色尺寸 | 活跃时占页面高度 12-22%，非填满页面 | 可接受，不强制 |
| A13 | 角色是动作主体 | 在做与页面主题相关的动作，非角落装饰 | 重生成，prompt 强调 actor role |
| A14 | 无红晕（v1.5.0 新增） | 脸部无粉色红晕/腮红，脸部是干净黑色墨迹 | 重生成，prompt 强调 NO blush + NO pink cheeks + NO rosy cheeks |
| A15 | 外观一致性（v1.5.0 新增） | 每页墨仔的泪滴形身体、大眼风格、小嘴、头顶小芽+两片叶、手绘墨迹质感完全一致 | 重生成，强化完整角色锁描述；确认人物卡URL未过期 |

## J. v1.5.0 新增实战检查项（基于10+轮迭代验证）

### J1. 卡片内容不重复（P2/P3 必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| J1.1 | 卡片数量 | P2/P3 恰好 N 张卡片，无第 N+1 张 | 重生成，强调 EXACTLY N cards + NO extra card |
| J1.2 | 卡片内容不重复 | 每张卡片标题和描述都不同，无卡片2/3内容重复 | 重生成，强调 Card 3 is DIFFERENT from cards 1 and 2 + NO duplicate content |
| J1.3 | 卡片图标无脸 | 卡片内图标是无生命物体，无小墨仔/无脸/无泪滴形 | 重生成，每个图标标注 inanimate icon (NO face, NO character) |

### J2. 标签不重复（封面/P5 必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| J2.1 | 标签数量 | 恰好 N 个标签，无第 N+1 个 | 重生成，强调 EXACTLY N tags + NO fourth tag |
| J2.2 | 标签不重复 | 每个标签只出现一次，无同一标签重复出现 | 重生成，强调 Each tag ONLY ONCE + NO duplicate tags |
| J2.3 | 标签位置 | 标签只在指定位置出现，无在其他位置重复 | 重生成，强调 tags ONLY at [position] + NO tags elsewhere |

### J3. 逻辑标题检查（金句页 P4 必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|

### J4. 5页差异化检查（跨页必查）

| # | 检查项 | 标准 |
|---|---|---|

| J4.3 | 身体动作差异化 | 5页墨仔的身体动作全部不同（站立/盘腿坐/踩石头/坐云上/举牌子等） |
| J4.4 | 张嘴拟人化 | 所有张嘴页（O形嘴）必须含粉舌，非全黑洞 |
| J4.5 | 嘴型小比例 | 所有嘴型都是SMALL小比例，无大嘴/大张嘴/夸张表情 |
| J4.6 | 无红晕 | 所有页墨仔脸部无粉色红晕/腮红 |

### J5. 随机数字防护（每页必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| J5.1 | 无随机数字 | 页面无 40%、10%、32s、28% 等无关数字/百分比 | 重生成，强调 The ONLY number is page number + NO random numbers |
| J5.2 | 页码唯一 | 页码只在左上角出现一次，无在其他位置重复 | 重生成，强调 page number ONLY ONCE upper-left |
| J5.3 | 墨仔周围无文字 | 墨仔附近无英文"Mozai"、随机文字或数字 | 重生成，强调 Area around character COMPLETELY BLANK |

### J6. 页数与内容匹配度（v1.5.1 新增，跨页必查）

| # | 检查项 | 标准 | 不通过怎么办 |
|---|---|---|---|
| J6.1 | 页数决定有依据 | 页数（4/5/6）是根据内容长度和信息量决定的，不是默认5页 | 回到选题阶段重新评估页数 |
| J6.2 | 4页版内容不过载 | 4页版的分析和方案要点不超过3个，金句和互动合并在P4 | 内容过多则升级为5页版 |
| J6.3 | 5页版内容不空洞 | 5页版有独立金句页和独立互动页，每页有足够信息支撑，不是硬凑 | 内容过少则降级为4页版 |
| J6.4 | 6页版有必要 | 6页版有多个独立案例/数据/场景需要分别呈现，或需要背景补充页 | 内容不足以支撑6页则降级为5页 |
| J6.5 | 每页信息密度合理 | 每页既有核心信息又有留白，不是信息过载也不是空洞无物 | 调整内容分布或页数 |

## 常见问题快速修复

| 问题 | 原因 | 修复方法 |
|---|---|---|
| 出现第二个角色 | prompt 不够强 | 重生成，强调 EXACTLY ONE + 角色 ONLY 在指定位置 + NO character in cards |
| 卡片/图标里出现小墨仔 | 图标被渲染成角色 | 重生成，每个图标标注 "inanimate icon, NO face, NO character" |
| 出现英文 MOZAI/SEEDLING | 模型误渲染 prompt 中的词 | 重生成，在 Avoid 列表明确列出，或后期裁剪 |
| 页码右上角重复 | prompt 不够强 | 重生成，强调 upper-left ONLY, no duplicate on right |
| 嘴巴每页都一样 | 未指定每页不同嘴型 | 重生成，每页 prompt 指定不同 mouth expression |
| 多余数字标注（50%、10%、32s、28%） | 模型误渲染 | 重生成，Avoid 列表加 random numbers, percentages, time labels + 具体例子 |
| P4 出现两个对话气泡 | prompt 不够强 | 重生成，强调 EXACTLY ONE speech bubble, NO second/duplicate |
| 封面数字与正文不一致 | 设计时未核对 | 生成前核对：封面N件=正文N件；不一致则增加卡片或改封面 |
| 文案与往期爆款重复 | 开头/结构/金句雷同 | 换开头（场景化切入）、换结构、换金句、换互动问题 |
| 角色太胖/太瘦 | 身体形状描述不够 | 重生成，强调 round plump teardrop (not slim, not spherical) |
| 文字错字/漏字 | 模型渲染不准 | 可接受小瑕疵，严重则重生成，减少文字量 |
