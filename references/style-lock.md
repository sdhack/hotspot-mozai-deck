# 视觉风格规范

## 核心风格

- 暖白、略有纤维或铅笔痕迹的纸张；
- 手绘墨线，线宽有自然变化，可见少量排线、点描或轻微晕染；
- 克制的浅蓝、浅桃、鼠尾草绿、淡紫色块；
- 细双线边框和少量角部装饰；
- 淡铅笔网格或小型无生命涂鸦形成统一质感。

这些是品牌语言，不是每页必须塞满的清单。信息清晰度优先于装饰数量。

## 背景与层级

默认使用淡网格、稀疏小涂鸦、局部排线和少量墨点。涂鸦只能是无生命、无脸的小图形，例如星星、叶子、铅笔、箭头、圆点或音符。

避免大片毫无纸张质感的纯白背景，也避免网格、涂鸦、标签和墨点同时高对比。角色周围可降低涂鸦对比度或密度，但底层纸张纹理可连续覆盖。

每页只设一个主要视觉焦点。百分比只是构图参考，不作为硬性 QA 数字：

- 内容主导：内容块为焦点，墨仔清晰但次要；
- 角色主导：墨仔及动作是焦点，标题和标签支持；
- 场景叙事：单一场景是焦点，文字最少。

边框、角花、波浪下划线和 pastel 标签按页面需要选用。封面通常保留较完整的品牌框架，内页可以适度简化，只要整套仍属于同一视觉系统。

## 文字策略

中文准确性高于“直接由图像模型生成”的完整感：

1. 首选无字或少字生成；
2. 用可控排版工具叠加标题、页码、标签和气泡；
3. 如果只能端到端生成，将可见文字限制为短标题和极短标签，并逐字核对；
4. 正文和来源放在图外文案中。

不要依靠拼音、偏旁拆字或无限负面词来保证文字。出现错误时优先后期替换文字区域。

自然语言颜色描述对不同工具更可移植。若某个模型可能把十六进制颜色代码当作可见文字，就不要在给该模型的 Prompt 中写代码；这是一项兼容策略，不是所有模型的普遍规律。

## 避免

- 光滑塑料 3D、照片写实、矢量扁平企业插画；
- 高饱和霓虹、大面积纯黑背景、浓重投影；
- 正式印刷体与手写风格混杂；
- 过度装饰导致文字和角色不可读；
- 背景小涂鸦出现眼睛、脸、墨滴角色或第二个墨仔。

跨页统一纸张、墨线、色板、边框家族和标题层级；允许场景、动作、视角与装饰密度变化。不要为“画风不变”强制每页使用完全相同的标签数量或固定位置。
