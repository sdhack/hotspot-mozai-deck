# 统一视觉风格模板（用户提供 · 2026-09-10）

用户直接给出"温暖手绘知识科普海报"统一视觉规范时使用本文件作为该次任务的视觉锁。它与
[early-style-reproduction.md](early-style-reproduction.md)、[v1.9-image-profile.md](v1.9-image-profile.md)
并列，是第三种可切换的成品风格。用户粘贴完整风格模板、或点名"按统一视觉风格 / 知识科普海报风"
出图时读取本文件。

## 六项硬性特征（缺一不可）

纸张真实纹理、黑色手绘粗线、低饱和水彩、中文板报式层级、中央萌系角色、四周轻量涂鸦。所有内容
位于安全边距内，文字区整洁可读，整体像插画师在米白纸上亲手完成。

## 媒介与线条

- 温暖米白、略泛黄的天然纸底：细微纤维、淡淡污渍、压痕、不均匀纹理；
- 主体粗黑马克笔 / 毛笔 / 铅笔手绘：线条自然抖动、粗细不一、边缘毛糙断续、有重复描画痕迹；
- 局部叠加低透明度水彩晕染、蜡笔或彩铅笔触，模拟真实纸本扫描；
- 内部密集、方向不完全一致的排线与涂黑；细节图标用轻盈灰黑速写线，形成主次对比；
- 纸面干净透亮，禁止灰雾 / 柔光 / 磨砂（沿用四轮校准的反灰雾锁）。

## 色彩

主色米白、炭黑、暖灰；辅助色仅低饱和半透明的粉橙、浅蓝、鼠尾草绿、淡紫、奶黄。彩色像水彩轻扫
纸面，不完全覆盖轮廓，允许轻微越界与不均。不用高饱和霓虹色。

**减重校准（2026-09-10 用户反馈"颜色都偏重"后追加）**：所有颜色宁淡勿浓——标题虽粗重但用带飞白
漏空的干墨，不堆实心黑块；角色身体排线之间留大量纸白缝隙与浅灰层次，透气不死黑；淡彩标签、镜片
透明度再提一档像被水洗过。画面内所有文字与数字一律黑色手写，数字严禁上色（模型爱把金额数字画成
红色，须在图标描述里逐处锁死"这串文字连同数字全部黑色，红色仅限指定的唯一警示符号"）。后处理在
Contrast×1.04 之外追加 `ImageEnhance.Color(im).enhance(0.88)` 降饱和兜底。

## 构图与版式（竖版 3:4，中心轴分层）

1. 顶部两枚小型淡彩标签【作为一组】水平居中并排（组合中心严格对齐画布垂直中轴线，严禁分立两角，
   沿用已验证的居中强制措辞）；
2. 上半部两行超大中文主标题，居中近满宽；
3. 标题下一行较小副标题 + 手绘波浪线 / 下划线；
4. 中下部视觉中心：萌系 IP 角色（见下）；
5. 角色周围散布主题相关的浅灰线稿图标；
6. 底部横向四枚手绘胶囊标签（注意：本模板封面默认四枚，与早期手账的三枚不同）；
7. 最外围纤细、略不对称的双线边框，四角叶片 / 藤蔓 / 丝带装饰。

留白充足，中心密集、边缘轻盈，手账呼吸感。

## 字体气质

主标题黑色、粗重、有力度，笔画宽窄不均带真实飞白；副标题较细，钢笔 / 秀丽笔；小标签朴素清晰。
避免印刷体 / 黑体 / 宋体 / 规则数字字体。**注意**：本模板明确要求粗重飞白标题，与 v2.11 的
"中细字重"规则相反——用户粘贴本模板时以模板为准（最新显式指令优先），不套用中细规则。

**字重校准（2026-09-10 用户反馈"字体太粗，要细一号"后定稿）**：按模板原样写"粗重飞白"出图会
偏厚。统一风格封面的主标题定稿为**细一号**：中等偏轻的黑马克笔/毛笔手写，笔画宽度约字高的
1/12，干净利落、只留少量飞白丝缕，严禁厚墨重刷与墨块；层级靠字号大建立，不靠笔画粗重。
纸底同理：默认用技能原有的明亮暖白（两参照）；仅当用户明确给图要求"打底"时才启用第三张
纸底颜色参照（见商汤落地要点），用完即弃，不作为默认。

## 角色设计（墨仔，仍受品牌不变量约束）

简洁饱满的深色几何轮廓：头大身小、短手短脚、圆眼、认真警觉又可爱的表情；顶部一枚小嫩芽（两片
浅鼠尾草绿叶）；内部黑色区保留密集手工排线与白色漏笔纹理；双手持主题道具（放大镜 / 毛笔 / 手机 /
书本 / 文件夹），道具黑白手绘轮廓 + 少量淡彩。**必须套用梨形体态一致锁**（上窄下宽，高约宽
1.1–1.2 倍，两臂两腿，无腮红，见 character-lock.md），不得因"原创萌系吉祥物"措辞而改变墨仔身份。

## 装饰语言

空白处自然散布小星星、圆点、音符、叶片、羽毛、纸飞机、铅笔、弯曲虚线等课堂涂鸦；背景可若隐若现
加对话框、卡片、二维码示意框、方格纸线，但透明度极低，不抢主体。

## 光影与成像

平面插画，无真实三维光照；仅角色脚下松散铅笔排线阴影；模拟高质量纸本扫描 / 编辑部手绘插图——
温暖、略有旧纸感、清晰但不数码锐利。

## 内容变量（逐页填充）

主题 / 顶部左标签 / 顶部右标签 / 两行主标题 / 副标题 / 中心角色及道具动作 / 四个底部标签 /
周围辅助图标。槽位无事实依据时不得补写地点、日期、人数或因果。

商业扁平插画、完美贝塞尔曲线、规整印刷字体、现代无衬线黑体、电脑生成感、塑料质感、复杂光影、强景深、

## 商汤通道落地要点（SENSENOVA-ONLY）

- **三参照通道（2026-09-10 用户指定"用某图背景颜色打底"后确立）**：第一张画风参照（只借纸纹 /
  黑线 / 淡彩 / 飞白，声明不提供构图参照），第二张墨仔角色卡（外观真值），第三张**纸底颜色参照**
  （用户指定底色的图，声明"仅取背景纸色与纸纹，绝不取构图与文字"）；Prompt 顶部逐张声明用途，
  并写死采样色值（如约 #faf5e9）。用户给底色参考图时先 PIL 采样空白区均值写入 Prompt，参照图
  降采样 ≤1024px 转 JPEG 控制请求体积（多图易触 ~10MB 网关上限）。
- 尺寸 `1536x2048`（3:4，均为 32 倍数），JSON edits 体，`prompt_extend:false`，`response_format:"url"`。
- 顶部标签沿用"作为一组居中"强制措辞（商汤高频把标签甩到两角）；角色沿用"数手臂恰好 2 条"硬约束。
- 落盘按 image-generation-protocol.md 统一后处理（Contrast×1.04 + Color×0.88 + 极轻暖偏），JPEG 正确文件头。

## 实测记录（2026-09-10 家长群假老师封面）

首版标签跑到两角、放大镜手与下垂手之外右侧多出一条手；重试强化"标签作为一组居中"与"两臂分工 +
数手臂自查"后一次通过：标签居中、四胶囊、墨仔两臂梨形、全部文字逐字正确、单一红色警示。第二轮
用户反馈"颜色都偏重"且金额数字"648"被画成红色：按上方减重校准（Prompt 减重指令 + 数字黑色锁 +
Color×0.88）重生后通过——淡彩水洗级、红色仅存唯一警示星、数字回黑。
