# Copy Template · 配套文案模板

墨仔第一人称视角，抖音图文配文，200-300字。

---

## 文案结构（6段，不可改顺序）

### 1. 钩子开头（1-2句）
- 接封面标题的钩子
- 用墨仔第一人称，口语化
- 可以用"我是墨仔"+ 一个具体动作/情绪

**模板**：
```
我是墨仔。
今天看到{{热点事件}}，我{{情绪动作}}。
```

**示例**：
```
我是墨仔。
今天看到四川凉山的老师被要求和"耻辱"合影，我手里的笔都掉了。
```

### 2. 事实陈述（2-3句）
- 说清事件核心事实（时间、地点、人物、冲突）
- 不添油加醋，事实可核查
- 用具体数字和细节

**模板**：
```
{{时间}}，{{地点}}，{{事件核心冲突}}。
{{一个具体细节或数字}}。
```

### 3. 三个要点（每点1-2句）
- 对应 P2 的 3 个问题/分析
- 每点用"第一/第二/第三"或"一是/二是/三是"
- 每点有判断，不只是陈述

**模板**：
```
这件事有三个问题：
第一，{{要点1判断}}。{{1句解释}}。
第二，{{要点2判断}}。{{1句解释}}。
第三，{{要点3判断}}。{{1句解释}}。
```

### 4. 解决方案/深度（2-3句）
- 对应 P3 的 3 个做法/方案
- 不用全列，挑最核心的 1-2 个说
- 给出可操作的方向

**模板**：
```
{{问题}}该怎么办？{{做法1}}、{{做法2}}、{{做法3}}，哪个不比{{错误做法}}有用？
```

### 5. 金句落点（1-2句）
- 对应 P3 或 P4 的金句
- 有记忆点，可被截图传播
- 不喊口号，有观点

**模板**：
```
{{金句第一行}}，{{金句第二行}}。
```

**示例**：
```
好的教育是点燃一把火，不是浇灭一个人的尊严。
```

### 6. 互动提问（1句）
- 对应 P4 对话气泡
- 具体、可回答，不是"你怎么看"这种空泛问题
- 引导评论区分享经历

**模板**：
```
{{具体互动问题}}？评论区说说你的看法。
```

## 完整文案模板（直接复制替换）

```
我是墨仔。
今天看到{{热点事件}}，我{{情绪动作}}。

{{时间}}，{{地点}}，{{事件核心冲突}}。{{一个具体细节或数字}}。

这件事有三个问题：
第一，{{要点1判断}}。{{1句解释}}。
第二，{{要点2判断}}。{{1句解释}}。
第三，{{要点3判断}}。{{1句解释}}。

{{问题}}该怎么办？{{做法1}}、{{做法2}}、{{做法3}}，哪个不比{{错误做法}}有用？

{{金句第一行}}，{{金句第二行}}。

{{具体互动问题}}？评论区说说你的看法。
```

## 标题模板

封面标题（两行，第二行有钩子）：
```
{{事件核心冲突}}？
{{反常识/情绪钩子}}
```

**示例**：
```
考低分就和耻辱合影？
这操作我看不懂
```

```
107名应届生入职一月被劝退
校招承诺成了废纸？
```

---

## 话题标签

2-3 个，选最相关的：
- `#{{热点关键词}}`（如 #教师耻辱合影）
- `#{{分类标签}}`（如 #教育争议）
- `#{{ broader 标签}}`（如 #教师尊严）

---

## 去 AI 味检查

写完后检查：
- [ ] 有没有"首先/其次/最后"这种机械连接词？→ 改成"第一/第二/第三"或自然过渡
- [ ] 有没有"综上所述/总而言之"这种空泛总结？→ 删掉，用金句代替
- [ ] 有没有"让我们一起"这种口号？→ 删掉，用具体互动问题代替
- [ ] 每段是不是长度差不多？→ 故意打散，有的段1句，有的段3句
- [ ] 有没有"值得深思/引人深思"这种套话？→ 换成具体判断
- [ ] 是不是太完整太完美？→ 留一点口语化的不完美，比如"我就想问"
