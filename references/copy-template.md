# 配套文案

## 目标

文案要让读者迅速理解发生了什么、为什么值得关注，以及墨仔的观察或实用落点。默认简体中文；长度和平台以用户要求为准，未指定时使用适合移动端阅读的中短文案。

## 先选结构

根据证据选择，不强制故事体：

- **有完整可靠过程材料**：起点 → 变化 → 冲突 → 结果 → 落点；
- **只有通报或核心事实**：事实开场 → 关键解释 → 实际影响 → 落点；
- **争议未定**：已确认事实 → 不同观点 → 尚待确认 → 墨仔观察；
- **公共提醒**：具体场景 → 风险信号 → 可执行做法 → 互动。

不要补写新闻中没有的现场、心理、对话、因果或结果。

## 墨仔第一人称

允许：

- “我看到这条通报时，先把三个时间点圈了出来。”
- “我更在意的是，后续有没有正式说明。”
- “我拿笔记下一个判断方法。”

不允许，除非用户提供真实素材并明确要求：

- “我也被骗过。”
- “我的朋友就在现场。”
- “我亲眼看见老师这样做。”

墨仔可以有观察、判断和角色动作，不能伪造真实人生经历。

## 语气

优先平等、具体和可执行。避免居高临下的“你必须”“你应该”“学会了吗”。安全、诈骗、灾害等场景可以使用明确行动提示，不必为了“去说教”把关键警示弱化成含糊表达。

自然过渡，不机械使用“第一、第二、第三”。如果编号能提升安全信息的清晰度，可以保留编号；“去 AI 味”不应损害可读性。

## 模板

**标题**：准确钩子，不夸大、不预设未证实结论。

**开头**：用一个已确认事实、具体时间点或读者场景进入。

**主体**：解释两到四个关键点；每个数字与事实卡一致。区分事实、来源观点和墨仔判断。

**落点**：给出观察、可执行信息或仍待确认的关键问题。

**互动**：邀请读者分享相关经验或关注点，不诱导网暴、猜测身份或传播未经证实的信息。

**话题标签**：通常 2–4 个，包含事件主题、内容价值和墨仔 IP；不蹭无关热词。

## 图文对应

文案中的场景必须与页面规划一致，但不要求每页机械塞入两个“可视觉化元素”。一页一个清晰动作或物件足够时，不增加无意义装饰。图中的短标题、数字和文案必须一致。

## 发布检查

- 核心事实、数字、时间和身份有来源；
- 已确认事实和观点明确区分；
- 没有虚构第一人称经历；
- 没有把推测写成因果；
- 没有不必要暴露普通个人或未成年人身份；
- 标题强度不超过证据强度；
- 来源链接与检索日期随交付提供。
