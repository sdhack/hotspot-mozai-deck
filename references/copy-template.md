# Copy Template · 配套文案模板

墨仔第一人称视角，抖音图文配文，200-300字。

> v1.7.0 核心变更：**去说教原则**——避免命令式、说教式口吻。标题用第一人称经验分享（"我自己的3个小习惯"而非"3个防坑做法，新生必看"），卡片内容用分享式（"收费先去官网确认"而非"只认官方群和通知"），文案用故事和场景切入而非直接给建议。墨仔是"一滴在纸上活过来的墨"，它是观察者和分享者，不是教导者。

---

## 文案结构（6段，不可改顺序）

### 1. 钩子开头（1-2句）
- 接封面标题的钩子
- 用墨仔第一人称，口语化
- **必须与往期爆款开头不同**（v1.2.0 新增）
- **v1.7.0 去说教：用场景/故事切入，不用直接说事或命令式开头**

**多种开头模板（轮换使用，避免重复）**：

**模板A：直接说事（最常用，但容易重复）**
```
我是墨仔。
今天看到{{热点事件}}，我{{情绪动作}}。
```

**模板B：场景化切入（v1.2.0 推荐，避免与爆款重复）**
```
我是墨仔。
每年{{时间节点}}，{{场景描述}}。
{{引出热点}}。
```
示例：
```
我是墨仔。
每年8月底9月初，大学校门口都有这样的场景：
新生拖着行李箱，手里攥着录取通知书，一脸茫然——"我下一步该干嘛？"
```

**模板C：反问切入**
```
我是墨仔。
问你一个问题：{{反问句}}？
别急着回答，先看看{{热点事件}}。
```

**模板D：故事/经历切入（v1.7.0 推荐，去说教）**
```
我是墨仔。
刚进{{场景}}那天，我以为{{预期}}。结果{{实际经历}}。
```
示例：
```
我是墨仔。
刚进新生群那天，我以为终于找到组织了。结果一晚上被私聊了三次——卖电话卡的、推培训班的、收班费的。
```

**模板E：数据切入**
```
我是墨仔。
看到一个数字：{{具体数字}}。
这个数字背后，是{{热点事件}}。
```

> ⚠️ **去重规则**：如果往期爆款用了模板A（直接说事），下一条必须用模板B/C/D/E。开头的第一句话不能与任何已发布内容相同。
>
> ⚠️ **v1.7.0 去说教规则**：优先使用模板D（故事/经历切入），让墨仔以"我也踩过坑"的分享者身份出现，而不是"我来教你"的教导者身份。

### 2. 事实陈述（2-3句）
- 说清事件核心事实（时间、地点、人物、冲突）
- 不添油加醋，事实可核查
- 用具体数字和细节
- **v1.7.0 去说教：用具体场景和细节描述，不用概括性判断**

**模板**：
```
{{时间}}，{{地点}}，{{事件核心冲突}}。
{{一个具体细节或数字}}。
```

### 3. 要点列举（每点1-2句）
- 对应 P2 的 N 个问题/分析（N 必须与封面数字一致）
- 每点用"第一/第二/第三/第四"
- 每点有判断，不只是陈述
- **v1.7.0 去说教：用"我发现""我踩过的"等分享式措辞，不用"你必须""你应该"等命令式措辞**

**模板**：
```
这件事有{{N}}个问题：
第一，{{要点1判断}}。{{1句解释}}。
第二，{{要点2判断}}。{{1句解释}}。
第三，{{要点3判断}}。{{1句解释}}。
（第四，... 如果N=4）
```

**v1.7.0 去说教措辞对照表**：

| 说教式（避免） | 分享式（推荐） |
|---|---|
| 你必须只认官方群 | 我自己的办法是，收费先去官网确认一遍 |
| 你绝不应该私下转账 | 有人私聊让我转账，我会先去淘宝京东比个价 |
| 新生必看的3个防坑做法 | 我自己的3个小习惯 |
| 3个最常见的新生群套路 | 3个我踩过的新生群套路 |
| 你应该先比价再下单 | 拿不准的，我就先放一放 |
| 千万不要相信群里的推销 | 群里最活跃的那几个，根本不是来交朋友的 |

### 4. 解决方案/深度（2-3句）
- 对应 P3 的 N 个做法/方案
- 不用全列，挑最核心的说
- 给出可操作的方向
- **v1.7.0 去说教：用"我自己的办法是""我会先..."等第一人称分享，不用"你应该""你必须"等命令式**

**模板（说教式，v1.7.0避免）**：
```
{{问题}}该怎么办？{{做法1}}、{{做法2}}、{{做法3}}，哪个不比{{错误做法}}有用？
```

**模板（分享式，v1.7.0推荐）**：
```
我自己的办法是：{{做法1}}；{{做法2}}；{{做法3}}。
```
示例：
```
我自己的办法是：群里说的收费，先去学校官网或者辅导员那里确认一遍；有人私聊卖东西，先去淘宝京东比个价；拿不准的，就先放一放，真急的事不会只在群里说。
```

### 5. 金句落点（1-2句）
- 对应 P3 或 P4 的金句
- 有记忆点，可被截图传播
- 不喊口号，有观点
- **必须与往期金句不同**（v1.2.0 新增）
- **v1.7.0 去说教：用观察和感悟，不用命令和警告**

**模板**：
```
{{金句第一行}}，{{金句第二行}}。
```

**金句类型参考**：
- 对比型："好的教育是点燃一把火，不是浇灭一个人的尊严"
- 行动型："大学第一课，学会管好自己的钱"
- 态度型："报到不慌，照着做就行"
- 反常识型："骗子比学长还热情"
- **观察型（v1.7.0推荐，去说教）**："新生群里最热情的人，可能最想赚你的钱"

> ⚠️ **去重规则**：金句不能与已发布内容相同或高度相似。

### 6. 互动提问（1句）
- 对应 P4 对话气泡
- 具体、可回答，不是"你怎么看"这种空泛问题
- 引导评论区分享经历
- **必须与往期互动问题不同**（v1.2.0 新增）
- **v1.7.0 去说教：用"你呢？""你遇到过吗？"等平等分享式提问，不用"你学会了吗？""你记住了吗？"等教导式提问**

**模板**：
```
{{具体互动问题}}？评论区说说，{{引导行动}}。
```

**互动问题类型参考**：
- 经历分享型："你开学踩过最坑的一笔消费是什么？"
- 经验提醒型："你报到那天最手忙脚乱的是什么？"
- 观点选择型："你支持现房销售还是预售制？"
- 求助型："你开学遇到过什么骗局？评论区提醒新生"
- **平等分享型（v1.7.0推荐，去说教）**："你进群第一天被私聊过什么？评论区聊聊，给新生们提个醒"

> ⚠️ **去重规则**：互动问题不能与已发布内容相同。避免用"你怎么看""你觉得呢"这种空泛问题。
>
> ⚠️ **v1.7.0 去说教规则**：避免用"你学会了吗""你记住了吗""你知道了吗"等教导式提问，改用"你呢？""你遇到过吗？""你有过类似经历吗？"等平等分享式提问。

## 完整文案模板（直接复制替换）

```
我是墨仔。
{{钩子开头，优先用模板D故事/经历切入，避免与往期重复，去说教}}

{{时间}}，{{地点}}，{{事件核心冲突}}。{{一个具体细节或数字}}。

这件事有{{N}}个问题：
第一，{{要点1判断，分享式措辞}}。{{1句解释}}。
第二，{{要点2判断，分享式措辞}}。{{1句解释}}。
第三，{{要点3判断，分享式措辞}}。{{1句解释}}。
（第四，... 如果N=4）

我自己的办法是：{{做法1}}；{{做法2}}；{{做法3}}。

{{金句第一行，观察型/感悟型}}，{{金句第二行}}。

{{具体互动问题，平等分享式}}？评论区说说，{{引导行动}}。
```

## 标题模板

封面标题（两行，第二行有钩子）：
```
{{事件核心冲突}}？
{{反常识/情绪钩子}}
```

**示例**：
```
考低分就和耻辱合影？
这操作我看不懂
```

```
107名应届生入职一月被劝退
校招承诺成了废纸？
```

```
开学先别买！
这4个坑每年坑哭新生
```

**v1.7.0 去说教标题示例**：
```
新生群里的套路
90%的人踩过！
```

## 话题标签

2-4 个，选最相关的：
- `#{{热点关键词}}`（如 #教师耻辱合影）
- `#{{分类标签}}`（如 #教育争议）
- `#{{ broader 标签}}`（如 #教师尊严）
- `#{{时间节点标签}}`（如 #开学季）

## 数据驱动的文案建议（v1.2.0 新增，基于实战数据）

### 高收藏高转发的内容特征

基于实战数据（校园贷防骗爆款：2.3万播放、247分享、205收藏），以下特征的内容收藏率和转发率最高：

| 特征 | 说明 | 示例 |
|---|---|---|
| 实用清单/指南 | 可以照着做、收藏备用 | "开学必备清单""避坑指南" |
| 防骗/避坑 | 可转发给亲友提醒 | "校园贷防骗""兼职骗局" |
| 具体数字 | 有具体金额/数量，有冲击力 | "4个坑""6件事""8000元" |
| 可转发理由 | 明确告诉用户"转给需要的人" | "转给你身边的新生""提醒更多人" |

### 低收藏低转发的内容特征

| 特征 | 说明 | 改进方向 |
|---|---|---|
| 纯社会评论 | 只有观点没有实用信息 | 增加"怎么办"的解决方案 |
| 空泛互动 | "你怎么看" | 换成具体经历分享型问题 |
| 无转发理由 | 用户不知道为什么要转 | 明确"转给XX人" |

### 发布时间建议

- **最佳时段**：15:00-16:00（实战数据：这个时段播放量是13点时段的466倍）
- 次佳时段：18:00-20:00（晚间高峰，待验证）
- 避免时段：13:00-14:00（流量低谷）

## 去 AI 味检查

写完后检查：
- [ ] 有没有"首先/其次/最后"这种机械连接词？→ 改成"第一/第二/第三"或自然过渡
- [ ] 有没有"综上所述/总而言之"这种空泛总结？→ 删掉，用金句代替
- [ ] 有没有"让我们一起"这种口号？→ 删掉，用具体互动问题代替
- [ ] 每段是不是长度差不多？→ 故意打散，有的段1句，有的段3句
- [ ] 有没有"值得深思/引人深思"这种套话？→ 换成具体判断
- [ ] 是不是太完整太完美？→ 留一点口语化的不完美，比如"我就想问"
- [ ] **v1.7.0 去说教：有没有"你必须""你应该""你千万不要"等命令式措辞？→ 改成"我自己的办法是""我会先..."等第一人称分享**
- [ ] **v1.7.0 去说教：有没有"新生必看""你学会了吗"等教导式标题/提问？→ 改成"我自己的3个小习惯""你进群第一天被私聊过什么"等分享式**

## 文案去重检查（v1.2.0 新增，交付前必做）

写完后，与已发布内容逐条核对：
- [ ] 开头第一句是否与已发布内容不同？
- [ ] 文案结构是否与往期爆款有差异？（如往期用了直接说事，这次用场景化切入）
- [ ] 金句是否与已发布内容不同？
- [ ] 互动问题是否与已发布内容不同？
- [ ] 话题标签是否有差异化？
- [ ] 文案中的数字（N件事/N个坑）是否与配图一致？
- [ ] **v1.7.0 去说教：文案口吻是否是分享者而非教导者？**

> ⚠️ 如果有任何一项与已发布内容高度相似，必须重写，不能发布。

## master-copywriting 合规检查（v1.8.0 新增）

> 当用户要求文案"符合 master-copywriting 标准"或希望发布级质量时，交付前对照本清单核查。核心原则：**Truth before Strategy. Strategy before Style. Fact Gate 失败 = 整篇失败。**

### 检查清单（对照 master-copywriting G1-G12）

**事实层（G1-G5，FAIL 则整篇失败）**
- [ ] 热点事实可核查（时间/地点/人物/官方回应，有来源），无编造数字/来源
- [ ] 数字跨文案/配图/封面一致（"3个问号"= 正文 3 点 = 配图 3 卡片）
- [ ] 无虚构第一人称经历（墨仔是 IP 拟人，不伪装真人"我的朋友""我的客户"等）
- [ ] 外部声明与事实匹配，不夸大

**目的层（G6）**
- [ ] IP 内容：观点 + 共鸣 + 互动完整达成；不是只有观点没有落点

**平台原生（G7，抖音）**
- [ ] 用"生活故事体"：起点→变化→冲突→选择→结果→落点，而非纯评论体
- [ ] 写"正在发生"的场景与具体动作（排队自我介绍、群里安静了几秒、盯着截图想了很久）
- [ ] 开头直接进钩子，不铺垫空泛背景

**人声/去AI味（G8 / H1+H2）**
- [ ] 长句按换气拆短，书面词换日常词
- [ ] 打散"第一/第二/第三"模板化排比 → 改口语化自然过渡（如"三个地方最让我坐不住"）
- [ ] 无"首先/其次/最后""综上所述""让我们一起"等套话
- [ ] 无"你必须/你应该/新生必看"等命令式（沿用去说教原则）
- [ ] 收口句动词与前文一致，无同音干扰

**画面感（与配图呼应）**
- [ ] 每格（每页）至少 2 个可视觉化元素，与配图场景一一对应（如封面=举手机看群，文案就写"发来一条自我介绍"）
- [ ] 金句可被截图传播，有观点不喊口号

**互动/CTA（master-copywriting IMPLICIT_ONLY）**
- [ ] 互动问题具体可回答，平等分享式（"你家家长群，有过这样的家长吗？"）
- [ ] 无显式引流/强 CTA

### 实战案例（家长群晒身份，v1.8.0）

- 原稿问题：偏"评论体"、"第一/第二/第三"排比有 AI 味、画面感弱。
- 改写要点：开头改成"正在发生"的现场（大家排着队自我介绍→有人发来一条自我介绍→群里安静了好几秒）；加"盯着截图想了很久"等可视觉化动作；"第一/第二/第三"改为"三个地方最让我坐不住"；事实与数字不变；标题与封面钩子呼应（"一条自我介绍/让家长群安静了"）。
- 结果：事实层全通过，平台原生与人声层达标。
