# 页面规划与 Prompt

## 先规划，再生成

建立 N 页页面表。N 由信息单元决定，范围通常为 4–6：

| 页 | 页面职责 | 可见文字 | 主场景 | 墨仔动作 | 表情 | 布局 | 参考图 |
|---:|---|---|---|---|---|---|---|
| 1 | {{封面/进入场景}} | {{短标题}} | {{场景}} | {{动作}} | {{表情}} | {{角色/场景主导}} | {{主卡等}} |
| … | … | … | … | … | … | … | … |
| N | {{收束/互动}} | {{一句话}} | {{场景}} | {{动作}} | {{表情}} | {{布局}} | {{参考图}} |

逐页检查：本页事实是否在事实卡中；动作是否能用两只手完成；毛笔规则是否与动作兼容；角色和正文是否挤在一起；实际像素是否为 3:4；页码是否连续、位置与字级跨页统一；边框外侧是否至少有 20px 留白。

## 成图版式合同（默认 P0）

除用户另行指定外，整套图每页必须遵守以下不可省略的成品约束：

1. **比例**：严格竖版 3:4。Prompt 中写明目标尺寸或 3:4 比例；生成后读取实际像素宽高复核，不能只看聊天预览。不是 3:4 的页面必须重做。
2. **页码**：共 N 页时，逐页唯一页码固定为 `01 / N`、`02 / N` … `N / N`。可按画面选择左上、右上、左下、右下、顶部居中或底部居中；一套图只能选择其中一个位置，并保持相同字级、内边距和视觉层级。禁止写成主题编号或 `06 / 04` 一类非页码组合。
3. **边框安全区**：统一使用与主题相称的手绘单线或双线边框。边框、文字、角色及装饰均不得触及画布边缘；边框外保留不少于 20px 的连续暖白纸张留白。角部装饰只能位于内框附近，不能侵占外留白。
4. **整套统一**：纸张、线稿、色板、边框家族和页码位置一致；允许各页场景与局部角花不同。
5. **修复边界**：比例、页码、边框安全区属于阻断项。只重生不合格页；不要通过裁切文字、角色或边框来凑比例。仅在画面已有足够空白边缘时，可安全扩展画布后复核。

## Prompt 顺序

统一使用：

```text
=== CANVAS ===
[严格竖版 3:4、目标尺寸（仅写当前工具支持的尺寸）、画布四边至少 20px 外留白；内缩手绘边框]

=== STYLE ===
竖版 3:4 手账新闻卡片；暖白至浅米黄、有轻微纤维颗粒的纸张背景，局部极淡浅灰方格纸纹理；黑色手绘铅笔线稿和轻微蜡笔排线，线条自然不均匀；仅以雾蓝、蜜桃粉、浅橄榄绿、淡奶黄作克制点缀；细手绘边框和少量低密度无生命涂鸦。不是摄影、不是塑料 3D、不是光滑矢量插画、没有霓虹渐变。

=== CHARACTER ===
[墨仔身份锚点、当前动作、表情和情境道具规则]

=== LAYOUT ===
[内容主导 / 角色主导 / 场景叙事；主视觉和低噪声区；内缩边框；固定页码位置 {{左上 / 右上 / 左下 / 右下 / 顶部居中 / 底部居中}}，全套同位 {{0N / N}}。封面可按需使用：顶部 0–2 枚短标签、最多两行标题与波浪下划线、一行副标题、中部单一情境、下方关键词胶囊；内页不要机械复用封面层级。]

=== CONTENT ===
[本页唯一主题、场景物件、准确的最少可见文字]

=== CONSTRAINTS ===
[只列本页真正重要的正向约束；按 P0/P1/P2 排序]

=== AVOID ===
[最多列少量高概率失败项，不重复正向描述]
```

`CHARACTER` 固定在 `CONTENT` 前。字段帮助组织和批量检查，但不声称对所有模型有固定倍数提升。

## 三层优先级

- **P0**：事实与数字准确；单一墨仔；身体形状、芽叶、眼睛和肢体正确；文字不误导。
- **P1**：场景、动作、表情、构图和页面职责一致。
- **P2**：边框、角花、网格、标签和装饰变化。

Prompt 发生冲突时删除 P2，不要用更多负面词补救。

## 布局模式

### 内容主导

适合事实、步骤、对比和解释页。内容块是焦点，墨仔是可清楚辨认的次要视觉主体。角色附近不放文字或高对比图标，极淡纸纹或网格可以连续。

### 角色主导

适合封面和情绪页。墨仔及主题动作是焦点。标题短、准确；钩子可以是反差、问题、利益点或共鸣，不默认制造悬念。

### 场景叙事

适合少文字、多画面的要求。每页一个场景和一个主要动作，文字限短标题、极短标签或一句金句。不要把事实段落塞进手机、黑板或气泡。

## 默认完整文字成图

默认工作流：

1. 先锁定每页最终文案；
2. 每页独立生成全部可见文字，逐条写明标题、正文、标签、页码与互动句的位置；
3. 将正文拆成短句、信息卡或清单，标题通常不超过两行，确保完整且可读；
4. 逐字核对标题、正文、数字、页码、标签与互动句。

只有用户明确要求留白、纯插画、少字版或后期排字时，才采用不含完整文字的替代工作流。遇到错字，最多两次定向重试；之后说明限制并等待用户决定是否切换为后期排字，不擅自交付少字版或图外文字。

### 执行要求

这是墨仔日更图文的默认模式。只有用户明确要求留白、纯插画、少字版或后期排字时才不启用：

1. 将该页所有可见文字逐条用引号列出，并说明标题、正文、页码、标签、气泡或互动句的区域；
2. 每页只承担一个结论；为保证可读性，标题最多两行，正文拆成短句或信息卡，不把图注式长段落塞入画面；
3. 使用同一张最小必要墨仔人物卡作为全页参考；不同页用不同动作和场景，不增加第二角色；
4. 生成后逐页放大核对每个汉字、数字、页码、标题与底部标签；错误页最多两次定向重试；
5. 所有通过 QA 的页面保存到当前工作区以主题命名的文件夹，按 `01-封面`、`02-…` 的顺序命名。不要只交付聊天预览或临时路径。

## 参考图策略

- 常规页：主卡；
- 侧/背面动作：主卡 + 三视图；
- 特定表情：主卡 + 表情卡；
- 核心设定卡：阅读后转成文字约束，不默认传入；
- 如果多图参考导致重复角色或人物卡文字进入画面，减少到一张干净主参考。

## 工具适配

开始生成前读取当前图像工具说明，确认：生成还是编辑、如何提供本地参考图、是否支持多图、尺寸和批量参数、返回结果形式。不得假定存在 `image_edit`、`request_list`、`FileBatchUpload`、固定模型名或固定分辨率。

若支持参考图编辑，使用最少必要参考图；若只支持新图生成，在 Prompt 中完整写入身份锚点，并接受一致性可能较低。若完全没有图像能力，交付页面规划和可复制 Prompt，不虚构已生成结果。

## 重试

失败后只针对观察到的问题修改：

1. 首次重试：删除冲突或次要装饰，强化一个关键问题；
2. 第二次重试：简化姿势、减少道具或换成更干净参考；
3. 仍失败：向用户说明限制并等待是否授权后期排字或局部修复，不无限重生成，也不擅自交付少字替代版。
